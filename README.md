Textwise is a TUI-based program powered by Node that generates "textmode"-styled mosaics based on provided images or procedurally generated gradients. It supports pixelated fonts and TrueType fonts, and includes all of the settings you need to fine-tune the output however you want.

**What is textmode art?**
[Textmode](https://polyducks.co.uk/pages/what-is-textmode/) is a style of pixel art derived from the early days of computers and game consoles where the only way to display pixels was by showing text. Textmode artists use a set palette and font, and sometimes a set background color, to carefully put together mosaics. These days, textmode art is no longer a graphics workaround, but an artstyle used thousands of artists by choice. My goal for Textwise was to generate good-looking mosaics resembling textmode art with a variety of different options.

Textwise is in no way related to AI-generated imagery. Images generated by Textwise are generated through a set algorithm and are not a result of processing training data.

## How do I use it?

Clone this repository in your terminal with `git clone https://github.com/man-o-valor/textwise.git` or download it from this page using `Code -> Download ZIP`. Next, install [Node.js](https://nodejs.org/) and run `npm i` from that folder. Now you can create images in your terminal with `node .`.

## How to add input images?

To add an image to the input pool, move it to the input/ folder. Supported formats are .png, .jpg, and .jpeg.
